# GroundWork Open Source

> GroundWork Open Source, Inc. builds GroundWork Monitor, an open-source-based IT and network monitoring platform (Nagios Core, Telegraf, Grafana, InfluxDB) for hybrid infrastructure. Its integration layer, the Transit Connection Generator (TCG), exposes a Controller REST API for feeding inventory, metrics, events, and downtimes into the GroundWork Foundation server. The platform is self-hosted; source lives on GitHub under the `gwos` org.

## APIs
- [TCG Controller API (Swagger 2.0)](https://github.com/gwos/tcg/blob/master/docs/swagger.yaml): 17 operations for agent config, inventory, metrics, events, downtimes, and lifecycle control. Auth via GWOS-APP-NAME + GWOS-API-TOKEN headers.
